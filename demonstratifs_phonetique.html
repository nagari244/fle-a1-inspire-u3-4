Ce, cet, cette, ces

Les démonstratifs avec les vêtements et les produits à manger : prononcer et réviser.

Rappel : le démonstratif montre un objet précis. Il s'accorde avec le nom : masculin ou féminin, singulier ou pluriel. Les noms avec un * sont féminins. Touchez 🔊 pour écouter.

👂 Attention à l'oral

cet et cette se prononcent de la même façon : [sɛt].
cet anorak = [sɛ.ta.na.ʁak] • cette robe = [sɛt ʁɔb]

🇲🇽 Comparez avec l'espagnol

este / ese → ce ou cet • esta / esa → cette
estos, estas / esos, esas → ces

A. Écoutez et répétez : ce [sə] ou ces [se] ?

ce [sə]

Comme dans le, de, je.
Le son est court. La bouche est arrondie et détendue.

ces [se]

Comme dans les, des, mes.
On sourit : les lèvres sont tirées, le son est fermé.

💡 À l'oral, pull et pulls se prononcent pareil ! C'est ce ou ces qui dit s'il y a un ou plusieurs objets.

ces + consonne → pas de liaison : ces pantalons, ces tomates*.
